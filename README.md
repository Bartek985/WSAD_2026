# Wordprese Theme for WSAD Website
## Introduction
WASD it is acronym for Ogólnopolskie Warsztaty Statystyki i Analizy Danych (National Workshop on Statistics and Data Analysis). This theme was made to encourage more people to follow this event.

## Installation
- Download this theme,
- Download and install addon [Carbon Fields](https://github.com/htmlburger/carbon-fields),
- Change setting Struktura stałych odnośników ("Permanent link structure") to Nazwa wpisu ("Post name")
- Login to your wordpress admin panel and set up your informations
